## How it is used

Ingest uses an extraction only when every quote is found **and** every compared field equals golden; then values come from the extraction and every citation from golden. Otherwise golden decides and the misses are listed in the ingest answer. Per-AD usage rows were matched to ADs by time (the first call completed after the cached extraction started); new rows carry the AD id.
